How it works

Use the Word ribbon menu or the shortcut Alt + B.

Enter an expression using Word’s built-in equation editor, then let WordMath calculate the result. The add-on sits directly in Word, which keeps the workflow smooth for calculations, solution checking, and report writing.

  • Calculations from the built-in equation editor
  • Shortcuts for equation solving and analysis
  • CAS-like manipulation, factoring, and transformations
  • Equation numbering and LaTeX document templates
